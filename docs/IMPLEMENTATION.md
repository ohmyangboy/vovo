## 已落地

### 界面与创作

- 侧栏顶部为生成工作台，下方直接列出生成记录，底部保留设置；成功生成立即加入列表，点选记录查看、播放、继续编辑或删除。浏览记录保留当前草稿，复用不同文稿前需要确认。
- 文稿直接编辑，支持导入与拖放、显式停顿、选段或短句试听；草稿与偏好自动保存。
- 单编辑区配紧凑声音工具栏；语速、文稿操作按需展开。选择声音自动确定模型，取消常驻设置栏和步骤编号。
- 工作台与记录保持单页：文稿区独立滚动，底栏合并试听、正式配音播放器、字幕、导出和生成；字幕校对按需打开，结果不再堆在文稿下方。
- 52px 单行顶栏参考本机 bobo 的 `public/style.css`；品牌、当前页面和设置处于同一行。macOS 按 [Tauri 窗口配置](https://v2.tauri.app/reference/config/#titlebarstyle) 使用 Overlay 与原生窗口按钮，保留拖动权限；其他系统继续使用原生标题栏。
- 无环境也可以浏览静态声音目录；资源准备合并为设置中的「一键准备全部」，资源维护与日志放在展开项中。
- 声音搜索、语言筛选、收藏、最近使用、克隆与声音管理统一到工作台的选声入口，不再保留重复的声音库页面。
- 声音试听进度嵌入对应卡片，文稿试听与正式配音共用一个底栏；试听结束恢复正式配音播放组件。关闭选声会取消尚未完成的声音试听；播放器卸载时停止音频。
- 支持系统/浅色/深色外观；720 × 620 小窗口下保留编辑区与主要操作。

### 私有声音

- 同一表单内确认授权、导入、识别、试听、校正并保存；3–20 秒选段调整与效果试听按需展开。
- 可先试听克隆短句；保存时自动准备声音示例，回到同一工作台。
- 参考片段复制到应用管理目录；保存后的声音不依赖用户原始文件路径。
- 可以重命名或删除声音；删除声音不会删除此前生成的配音。
- 同一声音可补充两段参考，总计最多三段；按目标语言选片段、同语言优先最新。兼容原来的单片段声音资料，新增文件在原子更新资料失败时撤回。
- 克隆前统一引导一键准备，避免录音导入、声音保存、试听分散要求补环境。

### 一键准备与声音库试听

- 一个可取消的后端任务检查环境、复用并下载缺失资源、批量生成全部 131 个预设声音的试听，准备支持设备上的克隆功能与已有私有声音的试听。
- 批量试听每个模型只载入一次，按语言复用管线；每个声音单独原子发布音频与元数据，中断后保留已完成部分。
- 试听元数据验证模型版本、示例文本、声音编号、文件大小与 SHA-256；完整试听不重新生成，损坏或过期试听重新准备。
- 声音库明确显示「可播放」「准备中」「等待准备」「待准备」；已完成试听在后台准备期间也能立即播放，预设试听点击不触发实时生成。
- `samples` 保存预设声音试听，清理 `previews` 中的文稿试听缓存不影响声音库。
- 克隆安装支持 uv 和 Python venv，缺少 FFmpeg 时将固定版本的工具安装到应用的克隆环境，无需用户自行执行终端命令。

### 任务、产物与交付

- Rust 统一单任务锁，生成/安装/下载共用带 ID 和递增序号的事件；前端过滤旧任务与乱序事件。
- 按任务 ID 取消，清理进程树；参考处理超时也走守卫清理。
- 在唯一临时目录生成完整产物，校验后发布；失败或取消不替换之前成功的结果。
- 正式生成保存 WAV / MP3 / SRT / TXT 与版本化 JSON 元数据，进入历史。
- 使用受限 asset protocol 播放音频，不在新流程中通过 JSON 字节数组传输长音频。
- 字幕根据实际句级音频长度累计，支持播放定位、文字校对与人工断行。字幕保存创建新版本，再原子更新清单。
- 导出只复制/序列化产物，新建独立版本文件夹；失败清理未发布目录，支持默认格式与自动导出。
- 收紧音频读取范围、文件编号与文件名校验，设置生产 CSP 与独立开发 CSP。

### 引擎修正

- 共享文本处理：保护小数、英文缩写与网址，保留普通括号内容，限制无标点长文本。
- 共享音频产物：检查异常样本、字幕时间轴、文件冲突，失败清理不完整输出。
- 停顿按实际 PCM 样本数累积，避免时间轴在长文本中漂移。
- Kokoro 按声音路由中文/美式/英式发音；推理使用明确的本地权重、配置和声音文件，不按需联网补资源。
- 固定 Kokoro / Qwen 模型 revision，记录产物对应 revision；检查下载清单与文件大小。模型维护不删除共享缓存。
- 环境修复复用已有 venv；英文发音资源未准备完整时明确失败，不再宣称首次生成会自动联网补齐。
- Qwen Base 按目标文本路由中文/英文/混读，英文保留更长语句并缩短额外停顿；输出变速使用 `atempo`，保持音高并同步字幕，不发送被模型忽略的速度/情绪参数。
